# User-controlled verification

These guides describe future verification, not executed checks. D77 prohibits all testing until the user starts it. Read the source handoff before running a build, service, installer or client. The existing isolated-testing architecture and server roster still govern protection of files, credentials, apps and personal services.

D79 authorizes compilation/build fixes only. The binary build now succeeds; the user has not authorized tests, app launch or MCP connections. HANDOFF.md records that exception and the actual result.
