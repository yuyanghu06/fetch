# Native interface assets

SVGs are shared native control icons and small product-identification marks.
The fonts folder contains bundled binary typefaces. Rendering/layout belongs to
components.rs and the shared surface/copy feedback widgets.

New Connect apps marks:

- claude-logo.svg: Claude mark from https://claude.com/icon.svg, fetched November12,2026.
- codex-logo.svg: OpenAI mark displayed by https://developers.openai.com/codex,
  extracted from that official page November12,2026; only web class/ARIA attributes
  removed. This is the OpenAI mark identifying Codex, not a newly drawn logo.

These marks identify their respective products and remain their owners' marks;
the repository's source license does not relicense those trademarks. Keep their
provenance and do not redraw or replace them with invented product marks.
