# HTTP application routes

Handlers use shared backend services. Application JSON responses include `next_steps` and are never cached. Host (or HTTP/2 authority) and optional Origin must match the configured local address; proxy headers grant no authority. Public resource metadata works, while authorization-server metadata reports unavailable until real native authorization exists. Protected reads authorize before query validation or filesystem metadata. No developer token bypass exists. HTTP mock-authority tests live outside production code.

runtime.rs adapts the selected installation/server/config/credential/auth/restart/tool routes to shared backend services. Native Settings authority is checked before manual-value parsing and Mac confirmation. Installed-tool arguments/results use original RawValue JSON. The management-tool adapter calls the same services and preserves application JSON guidance. All new handlers are unverified source in D77; no HTTP requests have been made.
