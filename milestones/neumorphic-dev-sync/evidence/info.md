# Native neumorphic evidence

figma-*.png are current official Figma reference renders. Other PNGs render the actual Desktop::view with disposable sample server/tool data, temporary application state and in-memory fixture keys. They do not launch Fetch or execute queued API tasks. The export redraws and draws the same widget instance, with bundled static Inter weights loaded, so enabled/disabled styles are represented correctly.

Both1248×900and760×520are captured. tools-scrolled proves inner scrolling; tools-minimum-scrolled shows card contents after scrolling the outer page at minimum size. Install popup covers the app, including navigation, while open. Original raw RGBA exports are converted to PNG and removed.

Source review additionally checks the normal/Shift RestartClicked mapping to the existing force_restart body. Mouse clicks themselves are exercised in the fixture; no server restart is executed. Appearance uses Iced's available drawing primitives; exact Figma inner-shadow pixel equality is not claimed. Native OS titlebar and real account/Keychain/Finder behavior are outside these images.
