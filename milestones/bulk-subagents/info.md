# Copy all and Paste all subagents

The Subagents toolbar shows Paste all, Copy all, the blue Add subagent button, then the Claude and Codex choices. Copy all reads the definitions in the selected app and Workspace folder into one clipboard bundle.

Paste all creates eligible definitions immediately in the selected app and folder. It preserves the text and relative subfolders when copying within the same app. When changing apps it uses the existing conversion route. A taken filename or conversion needing review is reported for that file, and the remaining eligible files are added.

Three focused checks passed, including real Workspace HTTP calls with disposable files and offscreen widget events. Independent review accepted the feature. The signed development build passed and its signature verified.
